The Traditional "As-Is" Transit & Attendance Workflow

STEP 1

Manual Dispatch

Supervisors assign drivers and vehicles verbally or using paper whiteboards without central scheduling.

STEP 2

Paper Boarding

Drivers manually tick employee names on paper sheets while driving at pickup checkpoints.

STEP 3

Blind Transit

Dispatchers have zero live location visibility. Detours, delays, and breakdowns rely on phone calls.

STEP 4

Manual Audit

Paper rosters are gathered weekly, manually typed into Excel, leading to billing disputes with factories.

• Human Error & Fraud: Lost paper registers, forged driver signatures, and untracked absentees.

Backend Design: Clean Architecture & CQRS Pipeline

🏛️ Clean Architecture (4 C# Projects)

  • • Domain Layer: Pure business entities, value objects & domain rules (Zero external dependencies).
  • • Application Layer: CQRS Commands & Queries, MediatR Handlers, Validation pipelines, DTO interfaces.
  • • Infrastructure Layer: EF Core DbContext, JWT authentication, ML HTTP client, PDF rendering engines.
  • • WebAPI Layer: Carter Minimal API routing modules, middleware, dependency injection configuration.

🔄 CQRS Pattern with MediatR

  • • Commands (Write Operations): Encapsulate state mutations (CreateBus, IngestTelemetry) with fail-fast FluentValidation.
  • • Queries (Read-Only Data): Optimized data projection queries (GetLiveFleet, RunAnalyseQuery) with zero side effects.
  • • MediatR Pipeline Behaviors: Automatic cross-cutting concerns: Logging, Validation, and Unit-of-Work.
  • • Atomic Unit of Work: Guarantees transactional consistency across multi-entity operations.

Automated 250m Geofencing & Machine Learning ETA

📍 250m Geofencing Detour Engine

  • • Haversine Spatial Computation: Calculates great-circle distance between live GPS coordinates and the nearest route polyline.
  • • 250-Meter Detour Threshold: If offset exceeds 250m, vehicle status is immediately flagged as 'Detour Alert' in real-time.
  • • Replay Attack Defense: Rejects any telemetry payload with a timestamp older than 15 minutes.
  • • Business Value: Stops unauthorized detours immediately, saving fuel and preventing missed stops.

🤖 Machine Learning ETA Forecasting

  • • Python 3.11 FastAPI Microservice: Asynchronous microservice serving trained LightGBM models (bus_eta_model.pkl).
  • • Feature Vector: Input metrics include GPS coords, speed, remaining stop distance, stop index, time-of-day traffic.
  • • Sub-50ms Inference Latency: Computes batch arrival predictions across all downstream pickup stops instantaneously.
  • • Fault-Tolerant Fallback: Reverts to kinematic distance/speed calculation if ML microservice is unreachable.
