\markboth{Abstract}{Abstract}

This report describes the design and implementation of \textbf{CST LePoint}, a full-stack, enterprise-grade platform built for the IT service company \textbf{CST (Canadian System Technology)} to digitize and optimize fleet tracking and worker attendance management. The solution solves the real-world operational challenges of manual transport rosters and lack of real-time visibility by offering real-time bus tracking via IoT modems, geofenced route-deviation notifications, automated biometric/RFID attendance checking, and interactive business intelligence (BI) layouts.

Furthermore, the system integrates a machine learning microservice built with FastAPI to predict Estimated Time of Arrival (ETA), duration of operations, and absence-risk assessment. Built using a robust technology stack including Angular 19, Tailwind CSS, .NET 8 (following Clean Architecture, CQRS with MediatR, and Carter module routing), and SQL Server, this system enforces multi-tenant security, strict data invariants, and containerized deployment via Docker.

\vspace{1.5cm}
\noindent\textbf{Keywords:} Fleet Management, Attendance Tracking, Clean Architecture, CQRS, Machine Learning, FastAPI, Angular, IoT Telemetry.
